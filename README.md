# D-CORE OPERATIONS — Digital Workflow Management System

> **Technology at the Core. Operations at Scale.**

D-CORE OPERATIONS is a technology and digital operations platform for managing DMK digital platforms, IT infrastructure requirements, active current works, work queues, and future innovation ideas.

---

## 🚀 Key Features

* 🟢 **Current Works**: Interactive Kanban workflow (`Backlog` → `To Do` → `In Progress` → `Review` → `Completed`) with drag-and-drop powered by `@hello-pangea/dnd`.
* 🟡 **Works To Be Done (Work Queue)**: Planned & approved requirements repository with one-click **Move to Current Work** stage transfer.
* 🔵 **Future Ideas**: Innovation vault to capture tech proposals with impact/complexity ratings and a **Convert to Project** pipeline.
* 📁 **Preloaded DMK Platforms**:
  - `Periyar.net` (https://periyar.net/)
  - `Makkalveeran.com` (https://makkalveeran.com/)
  - `Kalaignar.org` (https://kalaignar.org/)
  - `TVK Files` (https://tvkfiles.org/)
* 📊 **Operational Intelligence**: Interactive Recharts dashboards for project progress, task status distribution, work completion trends, priority breakdown (P0-P3), and team workload allocation.
* 🔍 **Global Search (`Cmd/Ctrl+K`)**: Instant search across projects, tasks, ideas, team members, and notes.
* 💾 **Data Persistence & Management**: LocalStorage abstraction layer (`DataService`), full **JSON Export**, **JSON Import** restore, and **Reset Demo Data** option.
* 🌐 **Public Landing Page**: Showcase landing page with hero banner, ecosystem showcase, and 6-step operational lifecycle flowchart (`IDEA` → `PLAN` → `BUILD` → `DEPLOY` → `OPERATE` → `IMPROVE`).

---

## 🛠️ Technology Stack

* **Framework**: React 18 + Vite
* **Styling**: Tailwind CSS v3 + Custom DMK Deep Red (`#9b111e`) Design System
* **Icons**: Lucide React Icons
* **Charts**: Recharts
* **Drag-and-Drop**: `@hello-pangea/dnd`
* **Animations**: Framer Motion

## ⚙️ Quick Start Instructions

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/d-core-operations.git
   cd d-core-operations
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run local development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

4. **Build production bundle**:
   ```bash
   npm run build
   ```
